# Indielife Home Assistant 애드온

Indielife에서 제공하는 여러 Home Assistant 애드온을 모아 관리하는 저장소입니다.
각 애드온은 별도의 하위 폴더에 설정·빌드 파일과 사용 안내를 갖습니다.

## 저장소 등록

1. Home Assistant의 애드온 스토어에서 저장소 관리 화면을 엽니다.
2. `https://github.com/indielife/ha-addons`를 추가합니다.
3. 스토어에서 원하는 애드온을 선택하고, 해당 애드온의 안내에 따라 설치·설정합니다.

## 애드온 목록

현재 제공하는 애드온은 다음과 같습니다.

| 애드온 | 설명 |
|--------|------|
| [Wallpad MQTT Bridge](wallpad-mqtt-bridge/README.md) | RS485 월패드·환기장치 MQTT 연동 |

애드온별 지원 기기, 설치·설정 방법, 소스 버전과 빌드 절차는 위 문서에서 확인하세요.
